## 🎯 Habit Tracker — `tracking/` Project

> A mini project built with **vanilla JavaScript** showcasing real-world DOM usage.

**Features:**
- 🧩 Add new habits using input + Add button
- 📊 Track progress — completed vs total habits
- 🔥 Streak counter to maintain consistency
- 🕐 Time-based greeting (Morning / Afternoon / Evening)
- 💬 Rotating motivational messages
- 📭 Empty state when no habits exist

**Concepts used:** `querySelector`, `addEventListener`, `innerHTML`, `localStorage`, template literals, conditionals

## 🌐 DOM — `DOM/` Folder

The **Document Object Model** represents an HTML document as a node tree. JavaScript uses the DOM to build interactive web pages.

```
document
   └── html
        ├── head → title, meta, link
        └── body → div, p, button, input ...
```

**Key DOM methods practiced:**

```js
// Selecting elements
document.getElementById('app')
document.querySelector('.card')
document.querySelectorAll('li')

// Modifying content
element.innerHTML = '<b>Hello!</b>'
element.textContent = 'Hello!'

// Changing styles
element.style.color = 'red'
element.classList.add('active')

// Handling events
button.addEventListener('click', () => console.log('clicked!'))
```
