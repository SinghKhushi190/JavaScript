## 🌐 DOM
 
The Document Object Model (DOM) is a programming interface that represents an HTML document as a tree structure, where each element is a node.
 
👉 JavaScript uses the DOM to:
- Access HTML elements
- Modify content
- Change styles
- Handle user events
